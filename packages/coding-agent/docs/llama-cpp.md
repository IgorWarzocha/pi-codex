# llama.cpp

llama.cpp is not supported by the shipped Pi-Codex runtime. Pi-Codex does not provide `/llama`, local-router setup, model downloads, or llama.cpp authentication.

The generic upstream foundations still contain historical model/provider concepts for compatibility. They do not make local models a maintained Pi-Codex workflow.

## Different from upstream Pi

Upstream Pi documents a llama.cpp router and model-management commands. Those instructions are intentionally unavailable in Pi-Codex. Use upstream Pi or a local-model client if llama.cpp is required.
